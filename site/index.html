YOURS TO RUN. YOURS TO REMOVE.

From checkout
to live context.

The full setup downloads roughly 3 GB of model artifacts inside your checkout. The bundled local VLM runner supports Apple Silicon. Python 3.10+ required.

Full local stack

git clone https://github.com/NomaDamas/catch-your-mind.git
cd catch-your-mind
sh scripts/setup_local.sh
.venv/bin/python scripts/run_local.py

Open http://127.0.0.1:8766, give consent and start observation.

Includes speech transcription, voice activity, face landmarks, a local scene VLM, and optional Companion replies. Model inference speed depends on your machine.

Connect an agent

python examples/live_context.py

With the local stack running, the WebSocket example subscribes to the same runtime at ws://127.0.0.1:8765.

MCP stdio is also available. A separately started MCP process has its own session; it does not automatically share the dashboard.

Read the integration guide ↗

Done experimenting? Stop the local stack with Ctrl-C, then remove its model files.

.venv/bin/python scripts/local_models.py remove --yes

Removal checks project ownership and open files. It keeps your source code and Python environment.

CLEAR BOUNDARIES

What to expect.

Is this real-time?

The local stream publishes context snapshots every 250 ms. That is the delivery cadence, not a promise that every model finishes within 250 ms. Speech uses three-second windows; scene descriptions run in the background. Queue depth, processing time and freshness are visible.

Does it recognize how I feel?

It measures expression-related facial movements and other observable signals. These are not proof of inner emotions, intent or deception. Optional model interpretations remain unverified.

Does installing it connect my LLM automatically?

No. Register MCP tools or consume the WebSocket stream in your existing agent. The full local launcher separately configures its bundled VLM for scene descriptions and Companion testing.

What leaves my computer?

This browser preview downloads code and model assets but does not upload camera frames, audio or typed text. The default full local stack processes media on loopback and stores observations in memory. Using an explicitly configured remote provider sends the selected text and context to that provider.

Is it ready for production?

This is an alpha release. Automated tests and fixture inference check the implemented paths, but cannot establish accuracy across people, languages, devices or environments. Review the release QA notes before integrating.
