# Original PG physical Context

`pg.physical.local` is an explicit, high-resource, local semantic provider. It executes the authenticated PG-InstructBLIP `generate.py` on the pinned original graph and a complete custom canonical state. It yields **untrusted visual estimates**, not force, temperature, friction, density or physical measurements. No LLM invocation, model download, install, automatic routing, cadence override or cloud call occurs. Actual PG canonical export, compatible historical runtime, trained identity, reference parity, measured resources and heldout quality remain unavailable until supplied and verified (#242/#105/#38).

`ProcessProvider.open(python, 'pg.physical.local', config)` delegates to one owned `PGCanonicalProcess`. Generation-enabled startup binds a frozen policy hash in its receipt. The original receipt/close-only path remains available unchanged. No injected model/caller callback is a production feature; small graph and child protocol fixtures test machinery only.

Configuration has exactly `graph`, `graph_sha`, `lock`, `lock_sha`, `canonical`, `canonical_sha`, `stage_root`, `generation`, `max_gap_ms`. Graph/canonical/runtime declarations follow the existing artifact/schema contracts. `generation` has `schema_version:1`, `prompt_sha256` equal to `humansense.pg_generation.PROMPT_SHA`, `execution` exactly equal to graph execution, `transport_allowance_bytes:134217728`, and explicit `generation_workspace_bytes` from 1GiB through 512GiB. `max_gap_ms` is 1..600000. Generation requires length penalty0/repetition penalty1; batch1, beams2..5, captions1..min(3,beams), prompt tokens1..128 and new tokens1..32 are already bounded in graph policy. No nucleus sampling or arbitrary generation kwargs.

The generation workspace is a separate operator allowance for the chosen CPU/CUDA target, not an inference memory guarantee. Loading destination/workspace cannot prove capacity for beam output scores, KV state, image and prompt intermediates. Actual peak admission stays unavailable. The transport allowance describes bounded copies, not a system-wide RSS guarantee; callers and multiple streams must separately budget retained originals and SDK queues.

## Capture and Context

Use `pack_capture(plain_uint8_rgb_array, [x0,y0,x1,y1], concept, track_provenance='caller.track')` to create immutable `InputFrame.data` bytes. The half-open object crop is explicit. RGB order is never guessed. `InputFrame` supplies original capture milliseconds, subject ID and `SensorMetadata` with RGB channels, coordinate frame and capture sequence. The SDK supplies its stream epoch when absent. Worker generation UUID and output delivery sequence remain separate from capture epoch/sequence. Caller track provenance is a declaration, never verified identity.

Maximum geometry is 4096 per axis and 8,388,608 pixels (25,165,824 raw bytes). Packed capture and worker packet are bounded to32MiB with a64KiB header. Shape/payload and hashes are verified before worker inference. SensorStreams retains its4MiB default; explicitly select `max_packet_bytes=32*1024**2` and a bounded overall queue allowance (example64MiB, capacity1) for maximum-size packets. Its existing maximum aggregate256MiB remains unchanged. No per-frame disk snapshots are created; only the existing canonical staging ownership/allowlist is used.

One native inference is admitted, with no implicit queue. The provider owns its internal operation task; close joins that task and native cleanup, including cancellation before its first step. Crop coordinates are copied into a bounded four-element snapshot before validation or pixel copying, so caller mutation cannot change the resulting packet. Writes are64KiB chunks with drain. One monotonic deadline covers writes, drains, response reads and validation. Partial/protocol errors, timeout or cancellation poison and reap the sole worker before cleanup. A late response cannot serve another request. Restart requires a new explicit open; reset during inference discards that response while preserving ownership until it drains.

The exact eval recipe is RGB object crop, square bicubic224x224, ToTensor, CLIP mean `(0.48145466,0.4578275,0.40821073)` and std `(0.26862954,0.26130258,0.27577711)`. Authenticated original eval source/config accompany the original generate source. Actual tokenizer input count is checked before generation; no silent truncation. Original `max_length` maps to T5 `max_new_tokens`. Raw `sequences_scores` are uncalibrated beam scores. Output-token count remains explicitly unknown rather than reconstructed from decoded strings.

SDK prompt/answer policy covers mass, fragility, deformability, material, transparency, contents, can-contain-liquid and sealed. Only the transparency prompt is the official supplied example; the other enumerated prompts/answer vocabularies are SDK policies. No semantic accuracy is asserted. Unknown/unrecognized or conflicting distinct alternatives abstain regardless of beam scores. No numeric confidence is fabricated. Raw alternatives remain tagged untrusted in Context.

Order checks are per source/sensor/capture epoch/subject/concept. Different concepts can inspect the same capture; same-concept duplicate/stale captures fail. State is bounded to128 subjects and8 concepts, reset on source/shape/epoch discontinuity or configured gap. New unknown replaces that concept's prior estimate. Returned Context describes only its original capture, never an earlier estimate retimestamped as current. History retrieval outside this provider must preserve last-seen/staleness semantics.

`examples/pg_physical_context.py` replays an explicitly supplied packet+capture metadata into SensorStreams and the MCP observation API. It does not invoke an LLM. Missing local assets/runtime fail closed; they never produce fixture estimates.

## Evidence boundary

Tests cover actual subprocess transport at the maximum RGB size, cleanup/cancellation/timeout/protocol failures, exact pinned original generate invocation on a tiny explicit machinery graph, original eval preprocessing parity, ownership/abstention/order and SDK→MCP Context. These are software evidence, not trained PG inference, historical runtime compatibility, physical correctness, cheap inference or demonstrated real-time performance.
