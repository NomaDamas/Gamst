# Qwen3-ASR-1.7B on a Mac, and hosted ASR adapters (2026-11-26)

## What was built (branch `feat/sota-asr`)

- `gamst/providers/whisper_phrases.py`: the phrase buffer takes any decoder. Whisper is one decoder; its behaviour is
  unchanged. Turbo on the same clip gives the same events as the base code (see below).
- `gamst/providers/qwen_words.py`: Qwen3-ASR-1.7B with Qwen3-ForcedAligner-0.6B word times, run through `qwen-asr`
  0.0.6's transformers backend on CPU or Apple MPS.
  - Package pins: transformers 4.57.6, torch 2.8.0, accelerate 1.12.0.
  - Weights: both snapshots, every file pinned by sha256. ASR revision `7278e1e7…`, aligner `c7cbfc20…`.
  - Output: the same `speech.transcript_words` records as Whisper. These are final phrases with capture-time word
    times. A phrase ends where the aligned words pause for 0.5 s or more (default, not tuned).
- `gamst/providers/hosted_asr.py`: Alibaba Model Studio `qwen-audio-3.1-asr-flash` (DashScope native API, word times
  in ms) and ElevenLabs Scribe v2 (`/v1/speech-to-text`, word times in s).
  - They follow the hosted-VLM rule: `allow_remote` (or `--allow-remote-asr`), https, and the key only from the
    variable that `api_key_env` names.
  - A cost line is printed before anything is sent.
  - Tested against a local stand-in server only. No key was available, so no paid call was made.
- Registry (`audio.asr`):
  - `qwen3.asr_1_7b.transformers` (cpu, mps).
  - `alibaba.qwen_audio_3_1_asr_flash.hosted` and `elevenlabs.scribe_v2.hosted`. Neither is automatic, and both
    have `allow_remote: false`.
  - `audio.word_alignment` `qwen3.forced_aligner_0_6b` is now the whole pinned snapshot, cpu/mps/cuda. It shares an
    environment with the ASR candidate.
- Recipe:
  - The `qwen-words` part sets up both roles.
  - A new `hosted-words` part.
  - `"bias": "terms"` gives the words being counted to the model before it listens: Qwen3-ASR's context prompt, or
    a hosted API's hot words / key terms. It uses the words given at the start of the run.

## Run on the 54 s shop clip (M2 Pro, other agents running)

How it was run:
- Recipe `person-term-count`, with the ASR module swapped and every other setting the same as the turbo recipe
  (phrases: hop 4 s, margin 3 s, max 25 s).
- Term `뽀또`.
- Truth: the owner's 10 word end times, scored at the end time ±0.6 s.
- "with voice" means `--voice voice.json --speaker-threshold 0.35`.
- Qwen ran on MPS in bfloat16. This was chosen by decode speed on this clip, not by its result.

What Qwen3-ASR wrote for the word, with no bias, decoding the 6 s before each time on its own (only the target
word is reported):
- 보도 at 12.0 and 38.2
- 보또 at 19.7, 20.1 and 22.3
- 뽀또 at 46.6 and 47.7
- 포도 at 12.6
- another word at 14.0, 21.5 and 28.1

With `context="뽀또"` it wrote 뽀또 at 12.0, 38.2, 46.6, 47.7 and 12.6, and still 보또 at 19.7, 20.1 and 22.3.

Plainly:
- On this clip Qwen3-ASR-1.7B is **not** better than turbo.
  - It writes the brand name in other spellings, so with no bias it counts nothing.
  - The context prompt brings it to 0.2–0.4 recall with voice (turbo: 0.5).
  - The context prompt also writes the word at 24.7 s, where nothing was said (turbo does too), and at 12.6 s
    (another voice).
- The same audio through the mp4 and the wav gave different Qwen results: 6 vs 11 counted with bias. The same wav
  twice gave identical results.
  - The likely cause is where the decode windows fall.
  - One clip cannot separate the models.
- Turbo now gives 6 counted / 5 right with voice. The 8 / 6 in `testbed-2026-11-26.md` was not reproduced. The
  unchanged base code (77f09d6) gives the same 6 / 5, so the difference is not from this branch.

## Published numbers (checked 2026-11-26)

- Qwen3-ASR Technical Report (arXiv 2601.21337):
  - FLEURS ko CER: 1.7B 2.57, 0.6B 3.72.
  - FLEURS 12-language average: 1.7B 4.90, Whisper-large-v3 5.27.
  - Common Voice: 9.18 vs 10.77.
  - The report has no Korean-only Whisper row; "3.54 vs 4.25" was not found there.
  - Forced aligner, Korean: 37.2 ms average shift.
- Open ASR Leaderboard, multilingual track (v1.16.3, 25 Nov 2026):
  - It covers 8 languages without Korean.
  - Open models: TheStageAI thewhisper-large-v3-turbo 4.31, NVIDIA Nemotron-3.5-Transcribe-30B-A4B 4.50,
    Omnilingual-ASR-LLM-7B-v2 5.89, Qwen3-ASR-1.7B 5.94, whisper-large-v3 7.76.
  - Nemotron (34.7–67.5 GB of weights, NVIDIA runtimes only) does not run on this Mac. thewhisper has no listed Korean
    and runs only through a token-gated CoreML SDK.
  - Among models that run here and have Korean, Qwen3-ASR-1.7B has the best published Korean number. Cohere
    Transcribe (2B, Korean listed) has no Korean number found.
- Hosted:
  - qwen-audio-3.1-asr-flash: $0.15 / 1M input tokens (Singapore). Alibaba does not call it Korean-optimised; only
    the `-message` variant says so.
  - Scribe v2: $0.20 / hour; key terms +20–25%. ElevenLabs lists Korean as "Good" (WER 10–20%).
