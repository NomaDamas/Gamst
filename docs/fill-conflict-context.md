# Same-capture conditional fill inspection

`FillConflictRuntime` compares the actual `CalibratedColorFill` image-grid boundary estimate with a strict, untrusted image-model interval from the **same owned BGR capture**. This is one supported predicate, `container_height_fraction_interval`, not a generic validator, physical truth, volume comparison or evidence the VLM is wrong. Calibration/liquid/empty-full verification flags stay false. The existing measurement record is retained separately and never overwritten with model output.

The application explicitly supplies HumanSense, a registered escalation-mode CallController and its existing CallBudget, fixed-view fill configuration, async small/optional strong clients with provider/model revisions, stage charge ceilings, chain authorization, unit/pricing revision and strong opt-in. `examples/fill_conflict_context.py` demonstrates a recorded-frame composition without any default endpoint, camera or model. Keep one driver/source alive across cases to preserve cooldown/history; do not create a fresh ledger to evade previous liabilities.

## Evidence and supported rule

The driver preflights plain uint8 BGR geometry (32..2048 each, <=2,097,152 pixels), declared BGR channels/capture epoch/sequence/calibration/coordinates, owns pixels before await/hash, and runs actual OpenCV. The versioned shape/layout/dtype/full-pixel digest binds both that input and the VisualContextCalls image. Two registered records share that capture: the original numeric measurement and a target-free ROI/container/config/image descriptor. All model stages receive the descriptor **without the measured interval, volume, prior claim or a desired numeric answer**. Source/subject/model/rule identities never come from generated JSON.

Claim JSON is at most1024 UTF-8 bytes, exact flat keys `schema_version:1`, `predicate`, `status`, `interval`. Estimated intervals contain exactly two finite nonboolean numbers in[0,1]; unknown has null. Duplicate/extra keys, fences, prose, nonfinite values, excessive nesting and numeric lexemes>32bytes/exponents outside±12 reject before arbitrary-precision construction. The parser never salvages partial JSON. Prompts are fixed by rule/stage with bounded declared ROI parameters; exact actual request hashes remain in controller/adapters.

`gamst.fill_height_interval.v1` uses exact rational decimal endpoints and guard1/20. Strict positive overlap means consistency only; touching/degenerate intervals are indeterminate. A positive disjoint gap<=0.05 is indeterminate (including equality); gap>0.05 is a **conditional image-model conflict**. This margin and the color provider's image-grid resolution are not statistical confidence or calibration-error bounds. Unknown/no-color/headspace/bottom/fragmentation cases cannot imply zero, full or refutation.

At most three calls: initial small; one small reinspection only following an actual private case conflict; optional strong only if that conflict remains unresolved and strong is explicitly enabled. Reinspection asks to inspect the same ROI again without supplying a numeric target. Every reply is re-parsed and compared with the same rule. A stronger answer remains an untrusted assertion. Failure/blocked stages are visible and do not silently skip to a stronger model.

## Admission, accounting and retention

Every actual call uses existing VisualContextCalls/controller reservation, dispatch, result acknowledgement and settlement. The three stage rule fingerprints differ; atomic `CallController.submit_next` allocates ordered submissions without resetting sequence, source state or ledger. The private case binds actual measurement/descriptor/full-image/rule/stage lineage, rather than accepting a caller conflict string as validation. Existing external-rule APIs remain unchanged.

Freshness is always min(controller max age, original1000ms fill/descriptor contract). It is rechecked before followups and final publication. A slow returned answer is historical with `blocked_stale_evidence`, original timestamp and insufficient-current quality; no retimestamping or replacement freshness capability. Default1000ms cooldown plus1000ms freshness can prevent reinspection: report the blocker, never silently relax the policy. The application may explicitly configure an appropriate policy.

Each stage ceiling is explicit integer currency quanta0..10^12 or unknown; total known ceilings must fit the explicit chain authorization<=3*10^12 with exactly the ledger's unit/pricing revision. This authorization is not a second ledger. Unknown ceilings block dispatch; unknown bills remain reserved liabilities, may block further stages, and can settle later through the authoritative controller. No token-to-currency inference, zeroing unknown costs or financial reset occurs. The optional existing evaluation observer records real VisualContextCalls backend entry; dispatch alone is not backend entry. In-process OpenCV is not falsely journaled as a spawned worker. Its local/preprocessing currency cost remains unknown, elapsed times are descriptive only, and `whole_chain_cost_complete` stays false pending external complete overhead evidence.

One active case, no hidden queue or parallel fanout; <=30s whole-case admission budget and0.01..10s stage timeout. Newer capture notifications cancel/supersede active work without retaining a second image; callers retry after the owned operation joins. Original capture order, processing generation and delivery sequence stay distinct. One runtime image<=6MiB plus bounded adapter copy, PNG<=8MiB/request<=12MiB; planned64MiB adapter envelope excludes model/worker memory and caller copies. Metadata cases<=16KiB, retained history32/<=512KiB and<=60s, diagnostic output<=64KiB with explicit omitted-history count. No raw pixels/prompts/answers in accounting diagnostics.

The shared owned call-driver registry (total8/per-kind4 including unreaped cleanup) handles pause/reset/revoke/delete/close. Invalidation scrubs internal sensory mappings synchronously, cancels owned work, closes source admission and joins owned OpenCV thread/adapter cleanup. Consent setters cannot await; the host retains cleanup ownership until terminal. Self/ancestor join is rejected after invalidation instead of deadlocking. External clients must cooperate with cancellation; externally retained copies cannot be forcibly erased by the SDK. Opaque unsettled financial liabilities survive sensory deletion.

## Acceptance boundary

Synthetic image + real OpenCV/controller/VisualContextCalls/Context/MCP tests establish software behavior. Async model fixtures do not prove semantic accuracy, calibration, cheap/faster inference or preserved quality. Actual container/negative calibration remains #109/#37, trained model semantics #40/#150/#133, and complete heldout cost/quality/p95 #57/#135/#161. Other predicates, cross-modal alignment and unseen-scene discovery remain separate required work.
